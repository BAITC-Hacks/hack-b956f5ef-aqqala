# План: Agentic AI для прогноза выработки ВЭС

Статус: **подтверждён 2026-09-23, в работе**. Отмечаем `[x]` по мере выполнения. Коммиты делает владелец репозитория вручную.

Порядок: сначала основной сценарий (данные → погода → модель → прогноз → агент на правилах → бэктест → Streamlit), затем подключение LLM, чтобы агент стал настоящим.

## Цель

Система по введённой дате и времени (момент выпуска прогноза) сама берёт архивные прогнозы погоды, доступные на тот момент, и выдаёт почасовой прогноз мощности на следующие 48 ч:
- по каждой турбине и итог по ВЭС;
- в долях от номинала, как в исторических данных.

Тест — прогнозы, выпускаемые ежедневно с 31.01.2026 по 27.02.2026 (покрытие 01.02–28.02.2026).

## Зафиксированные решения

| Тема | Решение | Основание |
|---|---|---|
| Погода | Open-Meteo **Previous Runs API**: GFS, ICON, ECMWF IFS | Проверено: day1/day2 есть с 16.02.2024 (ECMWF с 07.03.2024) |
| Без утечки | Цель T+h → `previous_day{ceil(h/24)}`: h≤24 → day1, 24<h≤48 → day2 | Используем только прогнозы, существовавшие на момент T |
| Часовой пояс | Данные в **фиксированном UTC+6**, внутри всё в UTC, ввод и вывод в UTC+6 | Кросс-корреляция ветра и температуры с прогнозами погоды; скачка 01.03.2024 нет |
| Координаты | T1 43.645150, 78.535604 · T2 43.643198, 78.538828 | Развёрнуты ссылки из задания |
| Выход | Доли мощности по турбинам + итог (среднее долей) + P10/P50/P90 | Требование: доли, как в истории |
| Новые турбины | Строка в `turbines.yaml` (id, lat, lon, cap) → загрузка погоды → общая модель парка | Требование: добавление по координатам |
| Кеш | Погода скачивается один раз в `data/weather/*.parquet`; прогноз и бэктест работают офлайн | Воспроизводимость для жюри |
| LLM | OpenAI-совместимый клиент: OpenAI **или** NVIDIA NIM (тот же API, другой `base_url`). Конкретная модель выбирается на этапе 8 по стоимости и качеству tool calling, обоснование в README | Кредиты $50 OpenAI + NVIDIA |
| Без ключа | Агент работает и без LLM: детерминированные правила вместо рассуждений LLM | Жюри может не иметь ключа |
| ML | scikit-learn `HistGradientBoostingRegressor` (loss=quantile) вместо LightGBM | Тот же класс моделей, без системной зависимости libomp, проще деплой |
| Окружение | `uv` + Python 3.12, `pyproject.toml`; `requirements.txt` для Streamlit Cloud | В системе только Python 3.9 |
| Репозиторий | Исходные CSV и кеш погоды коммитятся | Воспроизводимость |
| UI | Streamlit + deploy на Streamlit Community Cloud | Решение владельца |

## Архитектура (целевая)

```
turbines.yaml                  # реестр турбин
src/windcast/
  config.py                    # пути, модели погоды, TZ
  data.py                      # загрузка SCADA, UTC+6→UTC, 10 мин→час, чистка
  weather.py                   # Previous Runs → parquet-кеш; as-of выборка по T
  features.py                  # признаки: ветер по высотам/моделям, ρ, направление, обледенение…
  model.py                     # кривая мощности + градиентный бустинг (квантили), save/load
  forecast.py                  # forecast(issue_time) → DataFrame (турбины + итог)
  metrics.py                   # NMAE, NRMSE, bias; базовые модели
  agent/
    tools.py                   # инструменты агента (обёртки над модулями выше)
    loop.py                    # цикл LLM tool-calling + режим без LLM
    prompts.py
  cli.py                       # команды: download, train, forecast, backtest, add-turbine
app.py                         # Streamlit-интерфейс
outputs/                       # прогнозы (CSV/JSON), отчёты агента (MD), логи решений (JSONL)
```

Поток одного прогноза: `issue_time` → агент → проверка кеша погоды (докачать при необходимости) → проверка входов → признаки → модель → проверка результата → отчёт → при изменении входов перерасчёт.

## Известные ограничения (будут в README)
- Факта за февраль 2026 нет → точность на тесте не измерить, только на валидационных периодах.
- Честные прогнозы на 1–2 суток есть только с февраля 2024 → обучение на ~23 месяцах.
- Ремонты и ограничения мощности в будущем непредсказуемы.
- Previous Runs даёт разрешение по суткам (day1/day2), а не по каждому прогону (00/06/12/18Z).
